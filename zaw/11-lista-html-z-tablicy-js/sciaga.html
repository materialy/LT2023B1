Lista HTML z tablicy: map, join i innerHTML

Zanim zaczniesz

  • Template literal w odwrotnych apostrofach wstawia wartość przez ${…}: `Cena: ${cena} zł`.
  • map zwraca nową tablicę tej samej długości, a filter tylko pasujące elementy.
  • Strzałka bez klamer sama zwraca wynik: x => x * 2.
  • Element tablicy obiektów odczytasz w funkcji przez kropkę: p => p.nazwa.

Dane aplikacji trzymamy w tablicy, a na stronę zamieniamy je jednym wzorem: map robi z każdego elementu kawałek HTML, join('') skleja kawałki w jeden napis, a innerHTML wstawia go do strony.

Bez join('') pojawią się przecinki

Gdy do innerHTML trafi tablica, przeglądarka zamieni ją na tekst, wstawiając przecinki między elementy. Na stronie zobaczysz je między punktami listy.

Dla tablicy obiektów w szablonie odczytujesz właściwości:

tabela.innerHTML = produkty
  .map(p => `<tr><td>${p.nazwa}</td><td>${p.cena} zł</td></tr>`)
  .join('');

02Wyszukiwarka na żywo

Zdarzenie input zachodzi przy każdym wpisanym znaku. filter wybiera pasujące elementy, a funkcja rysuj wstawia je na stronę.

<input id="szukaj" placeholder="Szukaj owocu">
<p id="licznik"></p>
<ul id="lista"></ul>
<script>
const owoce = ['Jabłko', 'Banan', 'Gruszka', 'Ananas', 'Kiwi'];
// elementy strony (# oznacza id)
const szukaj = document.querySelector('#szukaj');
const lista = document.querySelector('#lista');
const licznik = document.querySelector('#licznik');

// rysuje podaną tablicę jako listę <li>
function rysuj(tablica) {
  lista.innerHTML = tablica.map(o => `<li>${o}</li>`).join('');
  licznik.textContent = `Znaleziono: ${tablica.length}`;
}

// po każdym znaku: małe litery po obu stronach, includes, filter
szukaj.addEventListener('input', () => {
  const fraza = szukaj.value.toLowerCase();
  const wyniki = owoce.filter(o => o.toLowerCase().includes(fraza));
  rysuj(wyniki);
});

rysuj(owoce); // na start cała lista
</script>

Wielkość liter: 'Banan'.includes('ban') daje false, dlatego obie strony zamieniamy na małe litery.

03Usuwanie z listy i rysowanie od nowa

let zakupy = [{ id: 1, nazwa: 'Mleko' }, { id: 2, nazwa: 'Chleb' }];

function usun(id) {
  zakupy = zakupy.filter(z => z.id !== id); // wszystkie oprócz usuwanego
  rysuj();                                  // strona pokazuje nowe dane
}

Zasada: najpierw zmieniasz dane w tablicy, potem wywołujesz rysuj(). Lista na stronie zawsze powstaje z tablicy.

04Typowe błędy

  • Brak .join(''): między punktami listy pojawiają się przecinki.
  • '<li>${o}</li>' w zwykłych apostrofach: na stronie widać dosłownie ${o}. Potrzebne są odwrotne apostrofy.
  • querySelector('lista') bez #: szuka znacznika <lista>, zwraca null i skrypt kończy się błędem.
  • toLowerCase() tylko po jednej stronie: „ban” nie znajdzie „Banan”.
  • zakupy.filter(…) bez przypisania: filter nie zmienia tablicy, nic nie zostanie usunięte.

05Słowniczek

innerHTML
zawartość elementu jako napis z HTML-em; przypisanie podmienia całą zawartość
join(separator)
skleja elementy tablicy w jeden napis; join('') bez żadnych odstępów
template literal
napis w odwrotnych apostrofach `…` ze wstawkami ${…}
querySelector
znajduje pierwszy element pasujący do selektora CSS, np. '#lista'; gdy go nie ma, zwraca null
addEventListener
podpina funkcję, która wykona się, gdy zajdzie zdarzenie, np. 'input'
zdarzenie input
zachodzi przy każdej zmianie tekstu w polu formularza
value
tekst wpisany w pole <input>
toLowerCase
zwraca napis zamieniony na małe litery
includes
sprawdza, czy napis zawiera podany fragment; zwraca true albo false
textContent
sam tekst elementu, bez interpretowania znaczników HTML
funkcja rysuj
własna funkcja, która od nowa buduje listę na stronie z aktualnej tablicy

06Sprawdź się

Odpowiedz w myślach, potem rozwiń.

Co zwraca ['a', 'b'].join(''), a co ['a', 'b'].join(', ')?

'ab' oraz 'a, b'.

Dlaczego szablon HTML piszemy w odwrotnych apostrofach?

Tylko w nich działają wstawki ${…}.

Po co na końcu skryptu jest wywołanie rysuj(owoce)?

Żeby lista była widoczna od razu po wejściu na stronę, zanim ktoś coś wpisze.

Jak usunąć z tablicy zakupy produkt o id 2?

zakupy = zakupy.filter(z => z.id !== 2); a potem rysuj();.

trudniejsze Co pokaże wyszukiwarka, gdy ktoś skasuje cały tekst z pola?

Wszystkie owoce. szukaj.value to wtedy '', a każdy napis zawiera pusty napis: 'Kiwi'.includes('') daje true.

trudniejsze Znajdź błąd: lista.innerHTML = owoce.map(o => '<li>${o}</li>').join('');

Zwykłe apostrofy zamiast odwrotnych. Każdy punkt listy pokaże dosłownie tekst ${o}.

trudniejsze Przewidź napis: String([1, 2].map(n => `<b>${n}</b>`))

'<b>1</b>,<b>2</b>'. Tablica zamieniona na tekst ma przecinek między elementami, dlatego potrzebny jest join('').
