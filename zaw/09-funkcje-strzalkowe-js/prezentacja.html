Funkcje strzałkowe

Krótszy zapis funkcji, który znasz z map i filter. Zobaczysz, jak powstaje ze „zwykłej” funkcji, kiedy potrzebne są nawiasy i return oraz czym strzałka różni się od function.

Zasady zapisu: oceń kafelki

Przy każdym kodzie wybierz: ✓ działa · ⚠ działa, ale zwraca undefined · ✗ błąd składni.

Strzałka nie ma własnego this

W zwykłej metodzie this to obiekt przed kropką. Strzałka tak nie działa. Przewidź, co zwróci każde wywołanie.

Wywołanie przed definicją

Czy można użyć funkcji w linijce wyżej, niż ją zapisano? Przy każdej wersji wybierz odpowiedź.

Znajdź 3 błędy

Kliknij linijki z błędem: składni albo „cichym”, gdy funkcja zwraca undefined. Potem kliknij „Sprawdź”.

Przepisz na strzałkę

Zapisz ten sam kod ze strzałką zamiast function. Zachowaj nazwy. Najkrótszy zapis jest najlepszy, ale wersja z klamrami i return też się liczy.

Do zapamiętania

  • Strzałka: (parametry) => wyrażenie albo (parametry) => { …; return …; }.
  • Jeden parametr: nawiasy można pominąć. Zero lub kilka: nawiasy obowiązkowe.
  • Bez klamer wynik zwraca się sam; z klamrami potrzebny return.
  • Obiekt zwracany wprost bierzesz w nawiasy: () => ({ a: 1 }).
  • Strzałki to wygodne callbacki: map, filter, sort, setTimeout.
  • Strzałka nie ma własnego this: metody z this pisz jako function.
  • Strzałkę w const wywołujesz dopiero poniżej jej definicji.
