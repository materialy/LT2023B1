Zanim zaczniesz

  • Funkcję deklarujesz słowem function, a wynik oddajesz przez return.
  • Funkcja bez return zwraca undefined.
  • W metodzie obiektu this oznacza obiekt przed kropką, np. kot.przedstaw().
  • map i filter przyjmują funkcję i wywołują ją dla każdego elementu tablicy.

Funkcja strzałkowa to krótszy zapis funkcji: zamiast słowa function piszesz strzałkę =>. Najczęściej trafia jako argument do map, filter, sort albo setTimeout.

02Zasady zapisu

Nawiasy przy parametrach

Jeden parametr: nawiasy można pominąć (x => …). Zero albo kilka parametrów: nawiasy są obowiązkowe (() => …, (a, b) => …).

Klamry i return

Bez klamer wynik wyrażenia jest zwracany automatycznie. Klamry tworzą zwykły blok kodu i wtedy trzeba napisać return.

// 1. jeden parametr, wynik zwraca się sam
const podwoj = x => x * 2;
// 2. kilka parametrów: nawiasy obowiązkowe
const dodaj = (a, b) => a + b;
// 3. bez parametrów: puste nawiasy
const powitanie = () => 'Cześć!';
// 4. kilka instrukcji: klamry i return
const srednia = (a, b) => {
  const suma = a + b;
  return suma / 2;
};
// 5. zwracamy obiekt: klamry w nawiasach okrągłych
const zrobKota = imie => ({ imie: imie, gatunek: 'kot' });

console.log(podwoj(21));           // 42
console.log(dodaj(2, 3));          // 5
console.log(powitanie());          // Cześć!
console.log(srednia(4, 6));        // 5
console.log(zrobKota('Filemon')); // { imie: 'Filemon', gatunek: 'kot' }

03Strzałka jako argument (callback)

const liczby = [10, 9, 1, 25];
liczby.map(x => x * 10);       // [100, 90, 10, 250]
liczby.filter(x => x >= 10);  // [10, 25]
liczby.sort((a, b) => a - b);   // [1, 9, 10, 25]: rosnąco
setTimeout(() => console.log('Minęła sekunda'), 1000);

Bez funkcji sort() porównuje elementy jak tekst: [10, 9, 1, 25].sort() daje [1, 10, 25, 9].

04Czym strzałka różni się od function

functionstrzałka
własne this (metody obiektu)taknie, bierze je z otoczenia
wywołanie w linijce wyżej niż definicjatak (deklaracja)nie, ReferenceError
krótki zapis jednym wyrażeniemnietak
 
const kot = {
  imie: 'Filemon',
  przedstaw: function () { return 'Jestem ' + this.imie; },
  przedstawStrzalka: () => 'Jestem ' + this.imie
};
kot.przedstaw();         // 'Jestem Filemon': this to kot
kot.przedstawStrzalka(); // 'Jestem undefined': strzałka nie ma własnego this

Reguła

Metodę obiektu, która używa this, pisz jako zwykłą funkcję. Strzałki zostaw na krótkie funkcje przekazywane do map, filter, sort i setTimeout. Strzałkę zapisaną w const wywołuj dopiero poniżej jej definicji.

05Typowe błędy

  • x => { x * 2 }: klamry bez return, funkcja zwraca undefined.
  • a, b => a + b: błąd składni, kilka parametrów trzeba wziąć w nawiasy.
  • => 42: błąd składni, bez parametrów też piszesz puste nawiasy ().
  • x => { imie: x }: JavaScript widzi blok, nie obiekt. Poprawnie: x => ({ imie: x }).
  • Wywołanie strzałki z const nad jej definicją: ReferenceError.

07Sprawdź się

Odpowiedz w myślach, potem rozwiń.

Jak zapisać strzałką funkcję bez parametrów, która zwraca napis 'Miau'?

const miau = () => 'Miau';. Puste nawiasy są obowiązkowe.

Kiedy nawiasy wokół parametrów można pominąć?

Tylko wtedy, gdy jest dokładnie jeden parametr, np. x => x + 1.

Co zwraca strzałka z klamrami, w których nie ma return?

undefined. Obliczenie się wykona, ale wynik nigdzie nie trafi.

Co zrobi setTimeout(() => console.log('Hop'), 3000)?

Po 3 sekundach wypisze w konsoli Hop.

trudniejsze Co wypisze console.log([3, 1, 2].map(x => { return x * x; }))?

[9, 1, 4]. W klamrach jest return, więc wyniki trafiają do nowej tablicy.

trudniejsze Znajdź błąd: const pole = a, b => a * b;

Dwa parametry bez nawiasów to błąd składni. Poprawnie: const pole = (a, b) => a * b;

trudniejsze Dlaczego kot.przedstawStrzalka() nie zna imienia kota, a kot.przedstaw() zna?

Zwykła funkcja dostaje this od obiektu przed kropką. Strzałka nie ma własnego this, bierze je z miejsca, w którym powstał obiekt, a tam nie ma właściwości imie.

Plik zaczyna się od wywołań, a strzałki w const są na samym dole. Jak to naprawić?

Przenieś definicje strzałek nad wywołania. Tylko deklaracje function można wywołać wcześniej.

    Podpowiedź

    Funkcja podziel ma dwie instrukcje (if i wynik), więc potrzebuje klamer i return.

    Rozwiązanie
    const dzialania = {
  dodaj: (a, b) => a + b,
  odejmij: (a, b) => a - b,
  pomnoz: (a, b) => a * b,
  podziel: (a, b) => {
    if (b === 0) return 'Nie dziel przez 0';
    return a / b;
  }
};
console.log(dzialania.dodaj(12, 4));  // 16
console.log(dzialania.podziel(12, 0)); // Nie dziel przez 0
