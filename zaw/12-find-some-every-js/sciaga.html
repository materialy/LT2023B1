Zanim zaczniesz

  • filter zwraca nową tablicę z elementami, dla których funkcja zwróciła true.
  • === sprawdza wartość i typ: 3 === '3' to false.
  • && wymaga spełnienia obu warunków, a || wystarczy jeden; ! odwraca wartość logiczną.
  • Właściwość obiektu w funkcji odczytasz przez kropkę: p => p.cena.

Metody find, findIndex, some i every przyjmują funkcję-warunek, tak jak filter, ale odpowiadają na inne pytania: który element pasuje pierwszy, gdzie on stoi, czy pasuje choć jeden, czy pasują wszystkie.

// Sklep Pod Lipą: produkty w tablicy obiektów
const produkty = [
  { nazwa: 'Ołówek', cena: 2, dostepny: true },
  { nazwa: 'Zeszyt', cena: 6, dostepny: false },
  { nazwa: 'Plecak', cena: 89, dostepny: true },
  { nazwa: 'Linijka', cena: 4, dostepny: true }
];
// wszystkie tańsze niż 5 zł → tablica (Ołówek, Linijka)
const tanie = produkty.filter(p => p.cena < 5);
// pierwszy niedostępny → obiekt Zeszyt
const brak = produkty.find(p => !p.dostepny);
// gdzie stoi plecak → 2
const gdzie = produkty.findIndex(p => p.nazwa === 'Plecak');
// czy coś kosztuje ponad 50 zł → true
const cosDrogiego = produkty.some(p => p.cena > 50);
// czy wszystko jest dostępne → false
const wszystkoJest = produkty.every(p => p.dostepny);

console.log(tanie.length, brak.nazwa, gdzie, cosDrogiego, wszystkoJest);
// 2 Zeszyt 2 true false

02Kilka warunków naraz: && i ||

// dostępne I tańsze niż 10 zł → Ołówek, Linijka
produkty.filter(p => p.dostepny && p.cena < 10);
// niedostępne LUB droższe niż 50 zł → Zeszyt, Plecak
produkty.filter(p => !p.dostepny || p.cena > 50);

03Co liczy się jako prawda: truthy i falsy

Falsy (jak false)

Tylko sześć wartości: false, 0, '', null, undefined, NaN.

Truthy (jak true)

Cała reszta, także '0', 'false', ' ' (spacja) i pusta tablica [].

Warunek nie musi zwracać dokładnie true. ['kot', '', 'pies', 0, null].filter(Boolean) daje ['kot', 'pies'], bo Boolean odrzuca wartości falsy.

Uwaga na zera

t.filter(x => x) usuwa też liczbę 0. Jeśli zero to prawdziwa dana (np. 0 punktów), sprawdzaj wprost: x => x !== null.

04indexOf i usuwanie powtórek

t.indexOf(x) zwraca indeks pierwszego wystąpienia wartości albo -1. Jeśli równa się bieżącemu indeksowi, element widzimy pierwszy raz:

const t = [3, 1, 3, 2, 1];
const unikalne = t.filter((x, i) => t.indexOf(x) === i);  // [3, 1, 2]

05Typowe błędy

  • t.filter(x => { x > 3 }): klamry bez return, wynik zawsze pusty [].
  • t.find(x => x = 3): jedno = przypisuje, warunek jest zawsze prawdziwy.
  • t.find(x => x === '3'), gdy w tablicy są liczby: tekst to inny typ, wynik undefined.
  • if (t.find(…) === -1): find nie zwraca -1, tylko undefined. -1 dają findIndex i indexOf.

07Sprawdź się

Odpowiedz w myślach, potem rozwiń.

Jaką metodą sprawdzisz, czy w koszyku jest choć jeden produkt droższy niż 100 zł?

koszyk.some(p => p.cena > 100), zwróci true albo false.

Co zwraca find, gdy żaden element nie pasuje?

undefined.

Czy pusty napis '' jest truthy czy falsy? A napis '0'?

'' jest falsy, a '0' jest truthy, bo to niepusty napis.

Czym różni się findIndex od indexOf?

findIndex przyjmuje funkcję-warunek, a indexOf szuka konkretnej wartości, np. t.indexOf(7).

trudniejsze Przewidź wynik: [2, 4, 7, 8].every(x => x % 2 === 0)

false. Liczba 7 jest nieparzysta, więc nie wszystkie spełniają warunek.

trudniejsze Znajdź błąd: const kot = koty.find(k => k.imie = 'Filemon');

Jedno = przypisuje: pierwszy kot dostanie imię Filemon i zostanie zwrócony. Poprawnie: k.imie === 'Filemon'.

trudniejsze Porównaj t.filter(x => x > 5).length > 0 i t.some(x => x > 5).

Dają tę samą odpowiedź. some jest krótsze i kończy szukanie na pierwszym pasującym elemencie, a filter przechodzi całą tablicę.
