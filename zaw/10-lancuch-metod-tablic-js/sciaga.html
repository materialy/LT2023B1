Zanim zaczniesz

  • map przekształca każdy element i zwraca nową tablicę tej samej długości.
  • filter zostawia tylko elementy, dla których warunek dał true.
  • forEach wykonuje działanie dla każdego elementu tablicy.
  • Strzałka z dwoma parametrami wymaga nawiasów: (a, b) => a + b.

Metody tablic można łączyć w łańcuch: każda działa na wyniku poprzedniej. filter wybiera, map przekształca, a reduce zwija całą tablicę do jednej wartości, np. sumy.

01Co zwraca każda metoda

Żadna z tych metod sama nie zmienia oryginalnej tablicy: wynik trzeba zapisać w zmiennej. Po forEach nie da się dopisać kolejnej metody, bo dostaje się undefined.

02reduce: z tablicy jedna wartość

const punkty = [4, 7, 2];
// (akumulator, element) => nowy akumulator, a 0 to wartość początkowa
const suma = punkty.reduce((akumulator, x) => akumulator + x, 0);
console.log(suma); // 13

03Łańcuch: filter → map → reduce

const ceny = [12, 8, 30, 5, 20];

const doZaplaty = ceny
  .filter(c => c > 10)                 // [12, 30, 20]
  .map(c => Math.round(c * 1.23))      // [15, 37, 25]: z VAT, zaokrąglone
  .reduce((suma, c) => suma + c, 0);  // 77

console.log(doZaplaty); // 77
console.log(ceny);      // [12, 8, 30, 5, 20]: oryginał bez zmian

04Tekst z formularza na liczby

const pole = '4, 7, 2';                     // tak przychodzi tekst z <input>
const teksty = pole.split(',');           // ['4', ' 7', ' 2']
const liczby = teksty.map(Number);         // [4, 7, 2]
const zle = ['1', '2', '3'].map(parseInt); // [1, NaN, NaN]: pułapka!

Dlaczego map(parseInt) psuje wynik?

map przekazuje funkcji element i indeks. parseInt traktuje drugi argument jako podstawę systemu liczbowego: parseInt('2', 1) i parseInt('3', 2) dają NaN. Używaj map(Number) albo map(x => parseInt(x)).

05Typowe błędy

  • const w = t.forEach(x => x * 2): w w jest undefined. Do przekształceń służy map.
  • .map(c => { c * 1.23 }): klamry bez return, same undefined, a suma wychodzi NaN.
  • [].reduce((s, x) => s + x) bez wartości początkowej: na pustej tablicy kończy się błędem TypeError.
  • .map(parseInt) na tekstach: część wyników to NaN.
  • Wołanie .map po reduce: reduce zwrócił liczbę, a nie tablicę.

07Sprawdź się

Odpowiedz w myślach, potem rozwiń.

Ile elementów ma wynik [5, 6, 7].map(x => x > 5)?

Trzy: [false, true, true]. map nie usuwa elementów, tylko je przekształca.

Po co w formularzu używamy split(',')?

Żeby pociąć napis, np. '4, 7, 2', na tablicę kawałków, które potem zamienimy na liczby.

Czy po const nowe = ceny.map(c => c * 2) tablica ceny się zmieni?

Nie. Nowe wartości są tylko w nowe.

Którą metodą wypiszesz każdy element w konsoli, jeśli niczego nie chcesz zwracać?

forEach, np. t.forEach(x => console.log(x)).

trudniejsze Przewidź wynik: [3, 12, 40].filter(x => x > 5).map(x => x / 2)

[6, 20]. Najpierw zostają 12 i 40, potem każda liczba jest dzielona przez 2.

trudniejsze Policz iloczyn [2, 3, 4] przez reduce. Dlaczego start nie może być 0?

[2, 3, 4].reduce((w, x) => w * x, 1) daje 24. Ze startem 0 każde mnożenie dałoby 0.

trudniejsze Znajdź błąd: ceny.forEach(c => c * 2).reduce((s, c) => s + c, 0)

forEach zwraca undefined, więc wywołanie .reduce kończy się błędem TypeError. Zamiast forEach użyj map.
